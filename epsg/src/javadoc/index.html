neoproj4j-epsg

This artifact contains no Java classes, so there is no API here to document. It ships the coordinate reference system dictionaries that neoproj4j reads off the classpath, under /proj4/ — the EPSG-derived CSV tables, the nad/ PROJ.4 name dictionaries, and the wkt/ definitions.

The API that reads these files lives in the neoproj4j artifact. Its javadoc is published alongside it on Maven Central and documents org.locationtech.proj4j.CRSFactory, org.locationtech.proj4j.api.Proj and everything else a caller touches.

This page exists because Maven Central asks for a -javadoc jar next to every published artifact, and the javadoc tool produces nothing at all for a module with no sources. An empty jar would satisfy the check while telling a reader who opens it nothing; this says where to look instead.
