neoproj4j-grids-us-legacy

This artifact contains no Java classes, so there is no API here to document. It ships two datum-shift grids redistributed verbatim from PROJ 9.8.1 — the CTABLE V2 files conus and alaska — under /proj4j-data/grids/, where the neoproj4j resolver chain finds them. Putting this jar on the classpath is the whole interface; there is no call to make.

The reader is org.locationtech.proj4j.datum.CTABLEV2 and the resolver chain is org.locationtech.proj4j.resource.ResourceResolvers, both in the neoproj4j artifact, whose javadoc is published alongside it on Maven Central.

This page exists because Maven Central asks for a -javadoc jar next to every published artifact, and the javadoc tool produces nothing at all for a module with no sources. An empty jar would satisfy the check while telling a reader who opens it nothing; this says where to look instead.
